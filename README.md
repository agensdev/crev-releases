# Crev

Utgivelser av Crev, Agens' macOS-app for code review av pull requests på GitHub og lokale endringer. Kildekoden ligger i det private repoet [agensdev/crev](https://github.com/agensdev/crev).

## Installer

1. Last ned [**Crev.zip**](https://github.com/agensdev/crev-releases/releases/latest/download/Crev.zip)
2. Pakk ut og flytt **Crev.app** til Programmer

Appen er signert og notarisert, og oppdaterer seg selv med [Sparkle](https://sparkle-project.org). Du kan også se etter oppdateringer under «Crev → Se etter oppdateringer …».

---

Dette repoet oppdateres automatisk av release-workflowen i agensdev/crev: hver versjon blir en release med `Crev.zip`, og `appcast.xml` peker på den nyeste.
